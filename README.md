# Abū Maʿshar al-Falakī — Moteur traditionnel v2

## Contenu
- thème natal : date/heure/fuseau/coordonnées
- Ascendant et maisons en signes entiers
- Soleil/Lune et positions planétaires approximatives
- Lots Fortune/Esprit et part relationnelle simplifiée
- profection + firdār
- moteur de jugement par domaine
- encyclopédie des méthodes
- PWA installable et hors ligne

## GitHub Pages
Déposer le contenu de ce dossier dans un dépôt public puis activer Settings > Pages > Deploy from branch > main / root.

## Limites
Les positions planétaires de démonstration ne remplacent pas une éphéméride astronomique. Les jugements astrologiques sont historiques/pédagogiques et non scientifiques ; le module maladie ne constitue pas un diagnostic.
